# Loops, conditions and parsing

Bash scripts covering \or\, \while\, \until\, \if\, \case\, arithmetic logic, and string splitting/parsing.

## Scripts

| File | Description |
|------|-------------|
| \1-for_best_school\ | Displays Best School 10 times with \or\ |
| \2-while_best_school\ | Displays Best School 10 times with \while\ |
| \3-until_best_school\ | Displays Best School 10 times with \until\ |
| \4-if_9_say_hi\ | Prints "Hi" on the 9th iteration of a \while\ loop |
| \5-4_bad_luck_8_is_your_chance\ | Prints specific words for 4 and 8 iterations |
| \6-superstitious_numbers\ | Superstitious loop using \case\ statement |
| \7-clock\ | Simulates 12 hours and 59 minutes display |
| \8-for_ls\ | For loop that displays content excluding parts before dash |
| \9-to_file_or_not_to_file\ | Information about a file using \if\ statements |
| \10-fizzbuzz\ | Classic FizzBuzz using \or\ and modulo arithmetic |
| \11-read_and_cut\ | Reads and parses \/etc/passwd\ with a \while\ loop |
| \12-tell_the_story_of_passwd\ | Parses \/etc/passwd\ using IFS in a while loop |
| \13-lets_parse_apache_logs\ | Parses Apache access logs with awk |
| \14-dig_the-data\ | Sorts parsed Apache log data by frequency |
